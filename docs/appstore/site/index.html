ピッと登録とは

スプレッドシートや CSV の商品リストに、カメラで読み取ったバーコード(JAN コードなど)を次々に割り当てていく iOS アプリです。棚卸し、商品マスタの整備、ネットショップの出品準備など、「表に JAN を手入力する」作業をまるごと置き換えます。

使い方

  1. 取り込む — スプレッドシートからコピーした表を貼り付けるか、CSV ファイルを読み込みます(UTF-8 / Shift_JIS 対応)
  2. スキャンする — 商品名を確認しながらカメラをかざすと、読み取り成功で自動的に次の商品へ進みます
  3. 書き出す — 結果をコピーしてスプレッドシートへ貼り付け、または CSV 保存・共有

特長

  • 対応バーコード: JAN-13 / JAN-8 / UPC-A / UPC-E / Code128 / Code39 / QR コード
  • 同じコードの二重読み取り防止・重複コードの警告つき
  • 読めないバーコードは手動入力で救済
  • 途中で終了しても、続きから再開できます
  • 完全オフライン。データはすべて端末内に保存され、外部へ送信されません

よくある質問

Q. データはどこに保存されますか?
お使いの iPhone の中だけに保存されます。本アプリはインターネット通信を行いません。詳しくはプライバシーポリシーをご覧ください。

Q. バーコードが読み取れません。
画面の黄色い枠に読みたいバーコードだけが入るようにかざしてください。暗い場所ではスキャン画面右上のライトボタンをお試しください。それでも読めない場合は「手動入力」から直接入力できます。

Q. Excel でも使えますか?
Excel からコピーした表の貼り付け、CSV ファイルの読み込み(UTF-8 / Shift_JIS)に対応しています。書き出した CSV は Excel でそのまま開けます。
