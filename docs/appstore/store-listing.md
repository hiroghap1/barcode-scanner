## 説明文(4000文字以内)

```
「ピッと登録」は、商品リスト(CSV・表データ)にバーコードを次々に割り当てていく、シンプルな業務ツールです。

棚卸し、商品マスタの整備、ネットショップの出品準備…。「エクセルの表にJANコードを1件ずつ手入力する」作業、大変ではありませんか?

ピッと登録なら:

1. スプレッドシートからコピーした表を貼り付け(またはCSVファイルを読み込み)
2. 商品名を見ながら、カメラをかざしてピッ!
3. 自動で次の商品へ。全部読んだら表をコピーして貼り付けるだけ

◆ 主な機能

・表の取り込み: コピー&ペースト / CSVファイル(UTF-8・Shift_JIS対応)
・列の割り当て: 「品番」「商品名」「JAN」などの列を自動で推定
・連続スキャン: 読み取り成功で音と振動、自動で次の未登録行へ
・誤登録を防ぐ仕組み: 同じコードの二重読み取り防止、登録済みコードの重複警告、読み取り範囲を絞るガイド枠
・カメラで読めないときは手動入力もOK
・途中で終了しても、次回続きから再開
・出力: スプレッドシートへそのまま貼り付けできるコピー、Excel対応CSV保存、共有

◆ 対応バーコード

JAN-13 / JAN-8 / UPC-A / UPC-E / Code128 / Code39 / QRコード

◆ 安心のローカル完結

インターネット通信は行いません。データはすべて端末内に保存され、外部に送信されることはありません。ログインも不要です。

現場の「めんどうくさい」を、ピッと解決。まずは手元の商品リストでお試しください。
```
