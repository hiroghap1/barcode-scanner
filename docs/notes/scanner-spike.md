# P0 スキャン技術スパイク記録

実機での検証結果を記録する。検証画面: アプリ内「バーコードスキャン スパイク」

## 前提知識(実装時の調査結果)

- VisionKit `DataScannerViewController` は **A12 Bionic 以降 + iOS 16+** が必要(`isSupported` で判定)
- **UPC-A は EAN-13(先頭 0 付き)として検出される**。VisionKit / AVFoundation とも独立したシンボロジー指定はない → 出力時にそのまま保存する方針(PRD の UPC-A 対応はこれで満たす)
- カメラはシミュレータ非対応のため実機必須
- `isAvailable` はカメラ権限を含めた実行時可否を返す

## 検証結果(2026-07-27、iPhone 16 Pro / iOS 26.5 実機)

| 項目 | VisionKit | AVFoundation |
|------|-----------|--------------|
| JAN-13(EAN-13) | ☑ | ☑ |
| JAN-8(EAN-8) | ☐ 未検証 | ☐ 未検証 |
| UPC-A(EAN-13 として検出) | ☐ 未検証 | ☐ 未検証 |
| UPC-E | ☐ 未検証 | ☐ 未検証 |
| Code128 | ☐ 未検証 | ☐ 未検証 |
| Code39 | ☐ 未検証 | ☐ 未検証 |
| QR コード | ☑ | ☑ |
| 読取までの体感速度 | ☑ 良好 | ☑ 良好 |

- ユーザー所感: 「しっかりスキャンできました」(両エンジンとも実用に足る)
- 未検証のシンボロジーは検出 API が JAN-13/QR と共通のためリスク低と判断。実物が入手できたタイミングで追検証する(P3 の 50 件連続テストでも確認機会あり)
- 小さいバーコード(〜2cm)・かすれ・低コントラストは未検証 → P3 完了条件のテストで確認する

## 判定

- [x] **VisionKit を第一候補として採用する**(主要ユースケースの JAN-13 が両エンジンで安定して読めた。DESIGN.md どおり AVFoundation はフォールバックとして維持)
- [x] クールダウン 1.0 秒は暫定適切(連続誤登録の報告なし。P3 の連続スキャンテストで最終確認)
